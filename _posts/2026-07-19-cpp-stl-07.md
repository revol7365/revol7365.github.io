`string` 클래스는 모든 문자 유형으로 인스턴스화할 수 있는 **연속 컨테이너 클래스**인 `basic_string`을 기반으로 한다.

```cpp
template<
    typename CharT,
    typename Traits = std::char_traits<CharT>,
    typename Allocator = std::allocator<CharT>
> class basic_string;
```

데이터는 `CharT` 타입으로 `data()` 멤버 함수를 통해 접근할 수 있다.
C++11 이후에는 `data()`가 반환하는 배열의 끝이 null로 종료되므로, `data()`는 `c_str()`과 동일하게 작동한다.

`std::string`은 `std::basic_string<char>`의 타입 별칭이다.

```cpp
namespace std {
    using string = basic_string<char>;
}
```

## string_view 클래스를 경량 문자열 객체로 사용하기

`string_view` 클래스는 `string` 클래스에 대한 경량의 대안을 제시한다.
`string_view`는 자체 데이터 저장소를 유지하지 않고, **연속된 문자 시퀀스**(C 문자열, `std::string`, 배열 등)에 대한 뷰로 동작한다.
그래서 `std::string`에 비해 더 작고 효율적이다.
`std::string`의 메모리 및 계산 집약적인 기능은 불필요하지만 문자열 객체가 필요한 상황에서 매우 유용하다.

### How to do it

```cpp
char text[]{ "hello" };
string greeting{ text };
text[0] = 'J';
cout << text << ' ' << greeting << '\n';
// Jello hello
```

```cpp
char text[]{ "hello" };
string_view greeting{ text };
text[0] = 'J';
cout << text << ' ' << greeting << '\n';
// Jello Jello
```

`string`은 원본 배열을 변경해도 객체가 바뀌지 않는다. `string` 생성자가 하위 데이터의 복사본을 생성하기 때문이다.
`string_view`는 다른 결과가 나오는데, 하위 데이터에 대한 뷰만 생성하고 자체 복사본을 가지지 않는다. 이는 효율적이지만 **원본 데이터가 `string_view` 객체 생명주기 동안 유지되어야 한다.**

```cpp
string_view sv() {
    const char text[]{ "hello" };  // 임시 저장소
    string_view greeting{ text };
    return greeting;
}

int main() {
    string_view greeting = sv();  // 데이터가 범위에서 벗어났다
    cout << greeting << '\n';      // 출력은 미정의
}
```

`string_view`에는 하위 데이터에 따른 생성자가 있다.

- 문자 배열(`const char*`)
- 연속된 레인지(`std::string` 포함)
- 다른 `string_view`

`std::literals` 네임스페이스에서 정의된 `string_view` 리터럴 연산자인 `sv`도 있다.

### How it works

`string_view`는 연속된 문자 데이터에 대한 효과적인 반복자 어댑터다.
`const CharT*`와 `size_t`를 멤버로 갖고, 원본 데이터에 대한 `contiguous_iterator`를 래핑해서 동작한다.
`string_view`는 몇 가지 차이를 제외하고 `std::string`처럼 사용된다.

**1. 복사 생성자는 데이터를 복사하지 않는다.** `string_view` 복사본을 만들면 각 복사본은 동일한 하위 데이터로 동작한다.

```cpp
char text[]{ "hello" };
string_view sv1{ text };
string_view sv2{ sv1 };
string_view sv3{ sv2 };
string_view sv4{ sv3 };
cout << format("{} {} {} {}\n", sv1, sv2, sv3, sv4);
text[0] = 'j';
cout << format("{} {} {} {}\n", sv1, sv2, sv3, sv4);

// hello hello hello hello
// jello jello jello jello
```

**2. `string_view` 객체를 함수에 넘기면 복사 생성자가 사용된다.**

```cpp
void f(string_view sv) {
    if(sv.size()) {
        char* x = (char*)sv.data();  // 위험함
        x[0] = 'j';                  // 원본을 변경
    }
    cout << format("f(sv): {} {}\n", (void*)sv.data(), sv);
}
```

여기서 하위 데이터의 주소는 모든 `string_view` 인스턴스에서 동일하다.

> **"근데 왜 `f` 안에서 `sv` 값이 바뀌지?"**
> `x[0] = 'j'`가 바꾼 것은 `string_view` 객체 자체가 아니라, `string_view`가 **가리키는 원본 데이터**다. `string_view`는 (포인터 + 길이)만 들고 원본을 가리키므로, `data()`로 원본을 얻어 고치면 그 원본을 공유하는 모든 `string_view`가 같이 바뀐 것처럼 보인다.
> 또한 `sv.data()`는 `const char*`를 반환하므로 `(char*)`로 const를 벗겨 쓰는 건 위험하다(원본이 진짜 const라면 미정의 동작). 위 예제는 원본 `text`가 non-const라 우연히 동작하는 것뿐이다.

`string_view` 클래스는 하위 문자열에 직접 동작하는 메서드가 부족하다. 그래서 `+` 연산자로 접합하려면 `std::string`이 필요하다.

```cpp
sv1 = sv2 + sv3 + sv4;  // 동작하지 않음

// 대신 string을 사용해야 한다
string str1{ text };
string str2{ str1 };
string str3{ str2 };
string str4{ str3 };

str1 = str2 + str3 + str4;  // 동작함
```

## 문자열 접합하기

C++에서 문자열을 접합하는 일반적인 방법은 다음과 같다.

1. `string` 클래스의 `operator+()`
2. `string` 클래스의 `append()`
3. `ostringstream` 클래스의 `operator<<()`
4. C++20부터 `format()`

### How to do it

**`std::string` 객체**

```cpp
string a{ "a" };
string b{ "b" };

string x{};
x += a + ", " + b + "\n";
cout << x;
// a, b
```

`string` 객체들은 리터럴 C 문자열에서 생성된다. C 문자열 생성자는 리터럴 문자열의 복사본을 만들고 그 지역 복사본을 `string` 객체의 하위 데이터로 사용한다.

**`append()` 함수**

```cpp
string x{};
x.append(a);
x.append(", ");
x.append(b);
x.append("\n");
cout << x;
```

**`ostringstream`의 스트림 인터페이스**

```cpp
ostringstream x{};
x << a << ", " << b << "\n";
cout << x.str();
```

**C++20의 `format()` 함수**

```cpp
string x{};
x = format("{}, {}\n", a, b);
cout << x;
```

### How it works

- `append()`는 데이터 끝에 새로운 데이터를 추가한다. 이를 위해 메모리를 할당·관리한다.
- `+` 연산자는 `operator+()` 오버로드를 사용하여 기존 데이터와 새 데이터를 포함하는 **새로운 `string` 객체**를 생성해 반환한다.
- `ostringstream` 객체는 `ostream`처럼 동작하지만 출력 결과를 문자열처럼 사용하기 위해 저장한다.
- C++20 `format()`은 서식 문자열과 가변 인자를 사용하여 새로 생성된 `string` 객체를 반환한다.

### There's more

벤치마크 결과:

| 방법 | 시간 |
| --- | --- |
| `append()` | 435ms |
| `+` 연산자 오버로드 | 659ms |
| `format()` | 782ms |
| `ostringstream` | 3463ms |

**성능 차이가 나는 이유**

- `append()`가 `+` 연산자보다 빠른 이유는, 메모리 할당은 하지만 **새로운 객체를 생성하지 않기** 때문이다. 그리고 `+` 연산자는 내부적으로 `append()`를 호출할 가능성이 높다.
- `format()`은 새로운 `string` 객체를 생성하지만 iostream 시스템의 오버헤드는 발생하지 않는다.
- `ostringstream`이 가장 느린 이유는, `operator<<`가 새 객체를 만들어서가 아니라(오히려 같은 스트림 참조 `ostream&`를 반환한다) 매 호출마다 sentry 생성·locale/facet 조회·streambuf 가상 함수 호출 같은 **iostream 기계장치의 오버헤드**가 붙기 때문이다.

**어느 방법을 선택해야 할까?**

- 속도가 중요하면 → `append()`
- 편의나 안정성이면 → `format()`이나 `+` 연산자
- 스트림 고유 기능이 필요하고 성능은 덜 중요하면 → `ostringstream`

## 문자열 변형하기

`std::string`은 연속된 컨테이너이므로 `transform()` 알고리즘이나 `contiguous_iterator` 컨셉을 사용하는 다른 기법과 함께 사용할 수 있다.

### How to do it

```cpp
char char_upper(const char& c) {
    return static_cast<char>(std::toupper(c));
}

char char_lower(const char& c) {
    return static_cast<char>(std::tolower(c));
}

char rot13(const char& x) {
    auto rot13a = [](char x, char a) -> char {
        return a + (x - a + 13) % 26;
    };
    if (x >= 'A' && x <= 'Z') return rot13a(x, 'A');
    if (x >= 'a' && x <= 'z') return rot13a(x, 'a');
    return x;
}
```

```cpp
string s{ "hello jimi\n" };
std::transform(s.begin(), s.end(), s.begin(), char_upper);

for(auto& c : s) c = rot13(c);
// 서술 함수 적용

for(auto& c : s) c = rot13(char_lower(c));
// 동일한 인터페이스 덕분에 서술 함수를 연쇄적으로 서로의 인자로 넘길 수 있다
```

### How it works

`std::basic_string` 클래스와 그 특수화(`string`)는 `contiguous_iterator`와 완벽하게 호환되는 반복자를 지원한다.
이는 연속 컨테이너에서 작동하는 모든 기법이 `string`에서도 동일하게 작동함을 의미한다.

- 단, `string_view`에서는 안 된다. 하위 데이터가 const(`data()`가 `const char*` 반환)이기 때문이다.

## C++20의 format 라이브러리로 텍스트 서식화하기

`format()` 함수는 파이썬 스타일의 서식 문자열을 사용하여 간결한 문법, 타입 안정성, 뛰어난 성능을 제공한다.

### How to do it

일반적인 서식화 해법:

```cpp
const int inta{ 47 };
const char * human{ "earthlings" };
const string_view alien{ "vulcans" };
const double df_pi{ pi };

cout << "inta is " << inta << '\n'
     << "hello, " << human << '\n'
     << "All " << alien << " are welcome here\n"
     << "π is " << df_pi << '\n';
```

`format()`은 문자열을 반환하므로 출력하려면 `cout <<`를 사용한다.
`std::print`(문자열 반환 없이 바로 출력)는 원래 C++20에 들어갈 예정이었으나 제외되었고 C++23에서 다시 추가되었다.

서식 문자열의 위치 옵션 제공:

```cpp
print("Hello {} we are {}\n", human, alien);
// Hello earthlings we are vulcans

print("Hello {1} we are {0}\n", human, alien);
// Hello vulcans we are earthlings
```

숫자를 위한 다양한 서식화 옵션:

```cpp
print("π is {}\n", df_pi);
// π is 3.141592...

print("inta is {1:}, π is {0:.5}\n", df_pi, inta);
// inta is 47, π is 3.1416

// [fill][align][width] 순서다.
print("inta is [{:*<10}]\n", inta);
// inta is [47********]   ('*' 채움, 왼쪽 정렬, 폭 10)

print("inta is [{:0>10}]\n", inta);
// inta is [0000000047]  ('0' 채움, 오른쪽 정렬, 폭 10)

print("inta is [{:^10}]\n", inta);
// inta is [    47    ]  (가운데 정렬, 폭 10)
```

### How it works

format 라이브러리는 파라미터 팩을 받아 타입이 소거된 인수들인 `format_args` 객체로 만들어 사용한다.

### There's more

사용자 정의 클래스에서 `format()` 지원을 제공하려면 `formatter` 객체 특수화를 생성해야 한다.

## 문자열의 공백 제거하기

`string` 클래스의 `find_first_not_of()`, `find_last_not_of()` 메서드를 사용하여 문자열 양 끝의 공백을 제거한다.

### How to do it

```cpp
string trimstr(const string& s) {
    constexpr const char * whitespace{ " \t\r\n\v\f" };

    if(s.empty()) return s;                       // empty string
    const auto first{ s.find_first_not_of(whitespace) };
    if(first == string::npos) return {};          // all whitespace
    const auto last{ s.find_last_not_of(whitespace) };
    return s.substr(first, (last - first + 1));
}
```

```cpp
cout << format("[{}]\n", trimstr(s));
```

### How it works

`find_...()` 멤버 함수는 위치를 `size_type` 값으로 반환한다.

```cpp
size_type find_first_not_of(const CharT* s, size_type pos = 0);
size_type find_last_not_of(const CharT* s, size_type pos = npos);
```

`find_first_not_of`는 기본적으로 처음(`pos = 0`)부터 앞으로, `find_last_not_of`는 기본적으로 끝(`pos = npos`)부터 뒤로 탐색한다.

## 사용자 입력으로 문자열 읽기

`std::cin` 객체를 사용하여 표준 입력 스트림에서 문자 기반 입력을 받는다.
`cin`은 콘솔에서 입력을 읽는 전역 싱글턴이며 iostream에서 동작한다.
`cin`은 스트림의 끝에 도달할 때까지 한 번에 한 단어를 읽는다.

### How to do it

`cin`에서 줄 단위 기능을 얻으려면 두 가지 동작을 이해해야 한다.

1. 한 줄씩 입력을 받는 기능
2. 오류 상태 발생 후 스트림을 초기화하는 기능

`cin.getline()`을 사용하면 입력 스트림에서 한 줄을 얻어 C 문자열 배열에 저장할 수 있다.

```cpp
cin.getline(s, MAXLINE, '\n');
```

- `cin.getline()`의 인자: C 문자열 배열, 배열의 크기, 라인 끝 구분자
- `std::getline()`의 인자: 입력 스트림, `string` 객체 참조, 라인 끝 구분자

`cin`은 오류를 만나면 스트림을 오류 조건으로 설정하고 더 이상 입력을 받지 않는다. 다시 입력을 받으려면 스트림 상태를 초기화해야 한다.

```cpp
void clearistream() {
    string s{};
    cin.clear();
    getline(cin, s);
}
```

## 파일에 있는 단어 수 세기

`basic_istream` 클래스는 한 번에 하나의 단어를 읽는다. `istream_iterator`를 사용하면 이 속성을 이용해 단어 수를 셀 수 있다.

### How to do it

```cpp
size_t wordcount(auto& is) {
    using it_t = std::istream_iterator<string>;
    return std::distance(it_t{is}, it_t{});
}
```

### How it works

`istream_iterator`로 단어 단위로 읽고, `distance`로 시작 반복자와 끝 반복자 사이의 개수를 계산한다.

## 파일 입력으로 복합 구조 초기화하기

입력 스트림의 강점은 텍스트 파일에서 서로 다른 타입의 데이터를 파싱해 각각에 맞는 타입으로 변환할 수 있다는 점이다.
데이터를 구조체 컨테이너로 import하는 방법은 다음과 같다.

### How to do it

```cpp
std::istream& operator>>(std::istream& in, City& c) {
    in >> std::ws;
    std::getline(in, c.name);
    in >> c.population >> c.latitude >> c.longitude;
    return in;
}
```

- `std::ws`로 입력 스트림의 앞쪽 공백을 제거한다.
- 도시 이름이 한 단어 이상일 수 있으니 `getline`으로 읽는다.
- `>>` 연산자로 나머지를 올바른 타입으로 읽는다.

```cpp
string make_commas(const unsigned long num) {
    string s{ std::to_string(num) };
    for(int l = (int)s.length() - 3; l > 0; l -= 3) {
        s.insert(l, ",");
    }
    return s;
}
```

### How it works

`operator>>` 오버로드로 입력 스트림이 사용자 정의 객체의 데이터를 읽는 방식을 지정할 수 있다.

### There's more

윈도우 BOM처럼 파일 앞쪽 세 바이트로 지정된 부분을 건너뛸 수도 있다.

## char_traits로 문자열 클래스 커스터마이징하기

### How to do it

대소문자를 구분하지 않는 문자열은 이렇게 커스터마이징할 수 있다.

```cpp
constexpr char char_lower(const char& c) {
    if(c >= 'A' && c <= 'Z') return c + ('a' - 'A');
    else return c;
}

class ci_traits : public std::char_traits<char> {
public:
    static constexpr bool lt(char_type a, char_type b) noexcept {
        return char_lower(a) < char_lower(b);
    }

    static constexpr bool eq(char_type a, char_type b) noexcept {
        return char_lower(a) == char_lower(b);
    }

    static constexpr int compare(const char_type* s1, const char_type* s2, size_t count) {
        for(size_t i{0}; i < count; ++i) {
            auto diff{ char_lower(s1[i]) <=> char_lower(s2[i]) };
            if(diff > 0) return 1;
            if(diff < 0) return -1;
        }
        return 0;
    }

    static constexpr const char_type* find(const char_type* p, size_t count, const char_type& ch) {
        const char_type find_c{ char_lower(ch) };
        for(size_t i{0}; i < count; ++i) {
            if(find_c == char_lower(p[i])) return p + i;
        }
        return nullptr;
    }
};
```

### How it works

`string` 클래스의 템플릿 특수화에서 `std::char_traits` 클래스를 사용자 정의 클래스인 `ci_traits`로 교체해 커스터마이징한다.

### How to do it

```cpp
template<typename It>
void get_links(It it) {
    for(It end_it{}; it != end_it; ) {
        const string link{ *it++ };
        if(it == end_it) break;
        const string desc{ *it++ };

        cout << format("{:.<24} {}\n", desc, link);
    }
}

int main() {
    const char * fn{ "the-end.html" };
    const std::regex link_re{ "<a href=\"([^\"]*)\"[^<]*>([^<]*)</a>" };
    // 이렇게 정규식을 정하고

    string in{};
    std::ifstream infile(fn, std::ios_base::in);
    for(string line{}; getline(infile, line);) in += line;

    std::sregex_token_iterator it{ in.begin(), in.end(), link_re, {1, 2} };
    // 일치하는 서브매치 1, 2를 it로 순회하며 출력
    get_links(it);
}
```

### How it works

STL regex 엔진은 한 번에 하나의 결과를 평가하고 산출하는 생성기처럼(lazy) 동작한다.
`sregex_token_iterator`는 지정한 **서브매치들을 각각 하나의 원소로 순회**할 수 있어서 `{1, 2}`처럼 뽑아낼 수 있다. `sregex_iterator`는 매치 전체(`match_results`) 단위로 순회하고, 서브매치는 `m[1]`, `m[2]`처럼 인덱스로 접근한다.
이를 통해 다양한 서식으로 결과를 추출할 수 있다.
