## 람다 표현식

C++11에서 도입됨
익명함수를 표현식의 컨텍스트에 사용할 수 있게 한다(??)
함수 호출, 컨테이너, 변수, 기타 표현식 컨텍스트에 사용될 수 있다

```cpp
auto la = []{ return  "Hello\n"; };
cout << la();
// la 변수를 함수인 것처럼 쓸 수 있다

f(la);
// 다른 함수에 넘길수도 있다

//다른 람다에 넘길 수도 있다
auto la = []{ return  "Hello\n"; };
auto lb = [](auto a){ return  a(); };
cout << lb(la);
```

## 클로저

자신의 어휘 범위 밖에 있는 심볼을 사용할 수 있도록 하는 함수

```cpp
auto la = []{ return  "Hello\n"; };
```

람다의 대괄호는 캡처 목록을 저장하는데 쓰인다
캡쳐는 람다 본문 범위에서 접근할 수 있는 외부 변수다

만약에 캡쳐 목록을 지정하지 않고 외부 변수에 접근을 하려고 하면

```cpp
const char* greeting{ "Hello\n" };
const auto la = []{ return greeting; };
cout << la();
```

```
in lambda function
error: "변수이름" is not captured
```

라고 나온다

(단, 이 오류는 `greeting`이 함수 안 **지역 변수**일 때 이야기다. 전역 변수라면 캡처 없이도 접근되고, 애초에 캡처 대상이 아니다.)

```cpp
const char* greeting{ "Hello\n" };
const auto la = [greeting]{ return greeting; };
cout << la();
```

이렇게 하면 정상동작한다

외부 범위에 있는 변수를 캡쳐하는 기능이 람다를 클로저로 만든다

## 람다를 사용하여 범위가 지정된 재사용 가능한 코드 만들기

람다 표현식은 정의 후 저장하여 나중에 사용할 수 있다
인자로 전달하거나 자료구조에 저장하거나 다양한 컨텍스트에서 다른 인자로 호출할 수 있다

### How to do it

```cpp
auto one = [](){ return "one"; };
auto two = []{ return "two"; };
// 비어있는 인자 괄호 ()는 필수가 아니다
// 반환 타입은 컴파일러에 의해 추론된다

// 아래 함수에서 호출가능
cout << one() << '\n';
cout << format("{}\n", two());
```

많은 경우에 컴파일러는 자동 타입 추론을 통해 반환 타입을 결정할 수 있다
그렇지 않은 경우 -> 연산자를 통해 반환타입을 명시할 수 있다

```cpp
auto one = []() -> const char* { return "one"; };
auto two = []() -> auto { return "two"; };
```

람다는 후위 반환타입을 사용한다 -> 연산자 다음에 타입 명세를 기입한다
반환 타입이 명시되지 않으면 auto로 간주하고 후위 반환타입을 사용하면 인자괄호는 생략할 수 없다

다른 람다의 값을 출력하기 위한 람다를 정의한다

```cpp
auto p = [](auto v){ cout << v() << '\n'; };
// 람다를 인자로 받아 람다 본문에서 출력한다
p([]{ return "lambda call lambda"; });
```

auto 타입 인자를 사용하면 축약된 템플릿이 된다

C++20 이전에는 람다를 템플릿으로 만드는 유일한 방법이었지만 C++20부터는 캡쳐 대괄호 뒤에 template 키워드 없이 템플릿 인자를 명시할 수 있다

```cpp
auto p = []<template T>(T v){ cout << v() << '\n'; };

// 축약버전
p([]{ return "lambda call lambda"; });
```

익명 람다에 인자를 전달해야할 때는 람다표현식 뒤의 괄호 안에 넣을 수 있다

```cpp
cout << [](auto l, auto r){ return l + r; }(47, 73) << '\n';
```

람다에서 외부 스코프 변수에 접근하려면 대괄호 안에 캡처로 포함시켜야 한다

```cpp
int num{1};
p([num]{ return num; });

//  혹은 참조로
int num{0};
auto inc = [&num]{ num++; };
for (size_t i{0}; i < 5; ++i) {
  inc();
}
cout << num << '\n';
```

상태를 유지하는 로컬 캡처 변수를 정의할 수 있다

```cpp
auto counter = [n = 0]() mutable { return ++n; };
for (size_t i{0}; i < 5; ++i) {
  cout << format("{}, ", counter());
}
cout << '\n';
```

mutable 지정자는 람다가 캡처한 값을 수정할 수 있도록 한다
람다의 기본값은 const다

람다의 두가지 기본 캡쳐

```cpp
auto l1 = [=]{ return a + b; }; // 복사에 의한 캡쳐
auto l1 = [&]{ return a + b; }; // 참조에 의한 캡쳐
```

### How it works

람다 표현식에서 필수적인 부분은 캡쳐목록과 본문 뿐이다

**캡쳐목록**
람다식에서 무엇을 캡쳐할지 지정한다 `[=]`을 사용하면 모든 변수를 복사로, `[&]`를 사용하면 모든 변수를 참조로 캡쳐할 수 있다. 변수를 이름으로 `[x]`처럼 캡쳐하면 기본이 복사다.

**인자들**

```cpp
[]int(int a, int b){ return a+b }
```

인자는 괄호에 명시한다 하지만 지정자 혹은 후위반환 타입이 없다면 괄호는 생략할 수 있다

지정자 혹은 후위 반환 타입이 있다면 괄호는 필수다

```cpp
[]() -> int { return 47 + 73; };
```

**mutable 변경자**
람다 표현식은 기본적으로 const이다 이는 복사로 캡쳐된 변수를 수정할 수 없다는 뜻이다

```cpp
[a]{ return a++; }; // 오류가 나온다

[a]() mutable { return ++a; };
// 문제가 없다
```

**constexpr 지정자**
constexpr을 사용하여 람다 표현식이 상수표현식으로 간주되기를 명시적으로 지정할 수 있다

**예외 속성**
noexcept 지정자를 넣으면 람다가 어떤 예외도 던지지 않음을 선언할 수 있다

**후위 반환 타입**
기본적으로 return 문에서 추론된다 이는 auto와 유사하다(?)
-> 연산자를 사용하여 후위 반환 타입을 지정할 수 있다

## 람다를 알고리즘 라이브러리의 서술로 사용하기

### How to do it

```cpp
auto is_div_by(int divisor) {
    return [divisor](int i){ return i % divisor == 0; };
}

int main() {
    const vector<int> v{ 1, 7, 4, 9, 4, 8, 12, 10, 20 };

    for( int i : { 3, 4, 5 } ) {
        auto pred = is_div_by(i);
        int count = count_if(v.begin(), v.end(), pred);
        cout << format("numbers divisible by {}: {}\n", i, count);
    }
}
```

펑터를 서술로 사용할 수도 있다
이 때는 서술로 클래스의 인스턴스를 사용해야한다

```cpp
struct is_div4 {
	bool operator()(int i)
	{
		return i % 4 == 0;
	}
};

int count = count_if(v.begin(), v.end(), is_div4());

auto is_div4 = [](int i){ return i % 4 == 0; };
int count = count_if(v.begin(), v.end(), is_div4);
```

함수로 람다를 감싸서 람다 캡처의 장점을 활용하고, 해당 함수 컨텍스트를 사용하여 다른 인자를 갖는 동일한 람다를 생성할 수 있다

```cpp
auto is_div_by(int divisor) {
    return [divisor](int i){ return i % divisor == 0; };
}
```

### How it works

캡처가 없는 람다는 함수 포인터로 변환될 수 있다

```cpp
void(*fp)() = []{ cout << "foo\n"; };

bool (*fp)(int) = is_div4;
bool (*fp)(int) = [](int i){ return i % 4 == 0; };
```

## std::function을 다형적 래퍼로 사용하기

std::function은 함수를 위한 얇은 다형적 래퍼다 이 템플릿은 함수, 람다표현식 또는 기타 함수 객체를 저장, 복사, 호출할 수 있다

### How to do it

```cpp
int main() {
    deque<int> d;
    list<int> l;
    vector<int> v;
    //....

	// 컨테이너 내용을 출력하는 함수
    auto print_c = [](auto& c) {
        for(auto i : c) cout << format("{} ", i);
        cout << '\n';
    };

	// 익명 람다를 반환하는 람다
    auto push_c = [](auto& container) {
        return [&container](auto value) {
            container.push_back(value);
        };
    };
    
    // 컨테이너는 익명 람다에 캡쳐된다
	 const vector<std::function<void(int)>> 
	  consumers { push_c(d), push_c(l), push_c(v) };

    for(auto &c : consumers) {
        for (int i{0}; i < 10; ++i) {
            c(i);
        }
    }
}
```

### How it works

람다는 흔히 간접 참조와 함께 사용된다

```cpp
	// 익명 람다를 반환하는 람다
    auto push_c = [](auto& container) {
        return [&container](auto value) {
            container.push_back(value);
        };
    };
    
    // 컨테이너는 익명 람다에 캡쳐된다
	 const vector<std::function<void(int)>> 
	  consumers { push_c(d), push_c(l), push_c(v) };

```

consumers 컨테이너를 초기화하는데 push_c를 통해 호출된 익명 람다가 저장된다

### There's more

std::function 클래스의 특성은 다양한 목적에 유용하다 일종의 다형적 함수 컨테이너로 생각할 수 있다

```cpp
function<void(void)> h = hello;


// 함수 인자들을 바인딩하는 std::bind를 사용하여 멤버함수도 저장할 수 있다
const function<void(void)> h = std::bind(&hello::greeting, &bob);

// 어떤 실행 가능한 객체를 저장할 수 있다
const function<void(void)> h = hello();
```

## 재귀로 람다 접합하기

한 람다의 출력을 다른 람다의 입력이 되는 방식으로 람다를 스택처럼 쌓을 수 있다

### How to do it

```cpp
using std::format;
using std::cout;
using std::string;

// 접합 함수 concat 이 함수는 람다 함수를 반환한다 파라미터 팩을 모두 소모할 때까지
template <typename T, typename ...Ts>
auto concat(T t, Ts ...ts) {
    if constexpr (sizeof...(ts) > 0) {
        return [&](auto ...parameters) { return t(concat(ts...)(parameters...)); };
    } else  {
        return t;
    }
}
```

```cpp
int main() {
    auto twice = [](auto i) { return i * 2; };
    auto thrice = [](auto i) { return i * 3; };
    auto combined = concat(thrice, twice, std::plus<int>{});
    std::cout << format("{}\n", combined(2, 3));
}
```

(2+3) x 2 x 3이 된다

## 서술을 논리적 결합으로 합치기

람다를 함수로 감싸 알고리즘의 서술로 사용할 정의 결합을 생성한다

### How to do it

```cpp
using std::format;
using std::cout;
using std::string;
using std::cin;
using std::istream_iterator;
using std::ostream_iterator;

template <typename F, typename A, typename B>
auto combine(F binary_func, A a, B b) {
    return [=](auto param) {
        return binary_func(a(param), b(param));
    };
}

int main() {
    auto begins_with = [](const string &s){ return s.find("a") == 0; };
    auto ends_with = [](const string &s){ return s.rfind("b") == s.length() - 1; };
    auto bool_and = [](const auto& l, const auto& r){ return l && r; };

    std::copy_if(istream_iterator<string>{cin}, {},
                 ostream_iterator<string>{cout, " "},
                 combine(bool_and, begins_with, ends_with));

    std::cout << '\n';
}
```

combine함수를 통해서 두개의 람다를 연결시킬 수 있다

## 같은 입력으로 여러 람다 호출하기

람다를 함수로 감싸면 서로 다른 캡쳐 값을 가진 람다 인스턴스를 쉽게 생성할 수 있다
이를 통해서 동일한 입력으로도 서로 다른 버전의 람다를 호출할 수 있다

### How to do it

값을 서로 다른 종류의 괄호로 감싸는 람다의 간단한 예제

```cpp
auto braces (const char a, const char b) {
    return [a, b](const auto v) {
        cout << format("{}{}{} ", a, v, b);
    };
}
```

세 문자를 출력하는 람다. 양끝값은 캡쳐, 가운데는 인자다

```cpp
int main() {
    auto a = braces('(', ')');
    auto b = braces('[', ']');
    auto c = braces('{', '}');
    auto d = braces('|', '|');

    for( int i : { 1, 2, 3, 4, 5 } ) {
        for( auto x : { a, b, c, d } ) x(i);
        cout << '\n';
    }
}
```

## 맵 기반 람다를 사용하여 점프 테이블 만들기

점프 테이블은 사용자 입력이나 기타 입력을 받아 행동을 선택할 때 유용한 패턴이다

### How to do it

콘솔로 입력을 받는 단순한 prompt()

```cpp
const char prompt(const char * p) {
    std::string r;
    cout << format("{} > ", p);
    getline(cin, r, '\n');

    if(r.size() < 1) return '\0';
    if(r.size() > 1) {
        cout << "Response too long\n";
        return '\0';
    }
    return toupper(r[0]);
}
```

익명 람다들을 로딩하여 점프 테이블을 구성한다

```cpp
int main() {
    using jumpfunc = void(*)();
    // alternately, std::function works too:
    // using jumpfunc = std::function<void()>;

    map<const char, jumpfunc> jumpmap {
        { 'A', []{ cout << "func A\n"; } },
        { 'B', []{ cout << "func B\n"; } },
        { 'C', []{ cout << "func C\n"; } },
        { 'D', []{ cout << "func D\n"; } },
        { 'X', []{ cout << "Bye!\n"; } }
    };
    
    char select{};
    while(select != 'X') {
        if((select = prompt("select A/B/C/D/X"))) {
            auto it = jumpmap.find(select);
            if(it != jumpmap.end()) it->second();
            else cout << "Invalid response\n";
        }
    }
}
```

## 궁금증

책 코드를 그대로 따라 쳤는데 컴파일이 안 되거나 좀 이상한 부분이 있어서 따로 정리해둔다.

### concat의 `[&]` 캡처 — 이거 위험하다

재귀로 람다 접합하기의 concat은 책에 `[&]`(참조 캡처)로 되어 있다.

```cpp
return [&](auto ...parameters) { return t(concat(ts...)(parameters...)); };
```

그런데 이 람다는 `combined`에 저장됐다가 **함수가 끝난 뒤에** 호출된다. `[&]`는 지역 매개변수 `t`, `ts...`를 참조로 잡는데, concat이 반환되는 순간 그 변수들은 스택에서 사라진다. 즉 사라진 변수를 가리키는 참조(댕글링)가 되어 **미정의 동작(UB)** 이다.

실제로 컴파일러도 경고한다.

```
warning: address of stack memory associated with parameter 't' returned [-Wreturn-stack-address]
```

예제에서 `combined(2, 3)`이 30을 잘 뱉는 건 최적화 없이 바로 호출해서 스택이 아직 안 덮였을 뿐이다. 운에 기댄 동작이라 최적화를 켜거나 컴파일러가 바뀌면 깨질 수 있다.

안전하게 하려면 `[=]`(값 캡처)로 바꿔야 한다. 값으로 복사하면 클로저가 자기 사본을 들고 있어서 함수가 끝나도 문제없다.

```cpp
return [=](auto ...parameters) { return t(concat(ts...)(parameters...)); };
```

### `[]<template T>` — 컴파일이 안 된다

람다를 템플릿으로 만드는 부분에서 책 코드는 이렇게 되어 있다.

```cpp
auto p = []<template T>(T v){ cout << v() << '\n'; };
```

이건 그대로는 컴파일이 안 된다.

```
error: expected '<' after 'template'
```

재밌는 건 책 본문 설명은 "`[]` 뒤에 **template 키워드 없이** 템플릿 인자를 명시한다"라고 되어 있어서, 설명과 코드가 서로 어긋난다. C++20 템플릿 람다의 올바른 문법은 `template`이 아니라 `typename`(또는 `class`)이다.

```cpp
auto p = []<typename T>(T v){ cout << v() << '\n'; };
```

책 오타로 보인다.
