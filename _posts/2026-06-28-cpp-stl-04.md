## 반복자가 기본

STL은 반복자를 사용하여 컨테이너 클래스의 요소에 접근할 수 있다 대부분의 컨테이너(아닌 컨테이너는?)는 begin()과 end() 반복자를 포함한다. begin() 반복자는 첫 요소, end() 반복자는 마지막 요소의 바로 뒤를 가리킨다
end() 반복자는 비결정적인 길이를 갖는 컨테이너를 위한 센티널 역할(?)을 한다
대부분의 STL 컨테이너는 고유한 반복자 타입을 정의한다

```cpp
std::vector<int> v;
std::vector<int>::iterator v_it;

std::vector<std::vector<int, std::string>> v;
std::vector<std::vector<int, std::string>>::iterator v_it;

// C++11은 자동 타입 추론과 auto 타입이 제공되면서 실제 타입을 사용할 일이 없다
for(auto v_it = v.begin(); v_it != v.end(); ++v_it)
{
	cout << *v_it << '\n';
}

// 위 코드는 아래 코드와 같다
// 반복자가 기본 포인터와 동일한 문법을 사용하기 때문에 레인지 기반의 for 반복문은 어느 컨테이너와도 동일하게 동작한다

{
	auto begin_it{ std::begin(container) };
	auto end_it{ std::begin(container) };

	for( ; begin_it != end_it; ++begin_it)
	{
		auto e{ *begin_it };
		cout << e << '\n';
	}
}
```

begin(), end() 멤버 함수를 직접 호출하는 대신에 std::begin(), std::end()를 호출하는 이유는 일반 배열과의 호환성을 가지기 위해서이다

- std:: 네임스페이스에 있는 비멤버함수는 기본 배열에서도 동작하도록 설계되었기 때문

## 반복자 카테고리

C++ 20 이전에는 기능에 따라서 반복자가 나눠져있었다

- **입력 반복자** — 한 번 읽고 증가할 수 있는 기능을 가진다
- **순방향 반복자** — 입력 반복자의 기능에 더해 여러번 증가할 수 있다
- **양방향 반복자** — 이러한 기능에 더해 감소할 수 있다
- **출력 반복자** — 한번만 쓰고 증가할 수 있다
- **가변 반복자** — 다른 반복자가 쓰기 기능을 함께 제공한다

## 반복자 컨셉

C++20부터 추가된 컨셉과 제약조건

- **컨셉** — 템플릿 함수나 클래스의 인자 타입을 제한하고 컴파일러가 적절한 특수화를 선택하도록 돕는 이름이 있는 제약조건

STL은 카테고리 대신 컨셉을 기반으로 반복자를 정의한다

```cpp
template<typename T>
requires std::random_access_iterator<typename T::iterator>
void printc(const T &c)
{
	for(auto e : c)
	{
		cout << format("{} ", e);
	}
	cout << '\n';
	cout << format("element 0: {}\n", c[0]);
}
```

위 함수에서 제약조건이 `random_access_iterator`인데 list로 함수를 호출하면 컴파일러 오류가 생긴다 list반복자는 `random_access_iterator` 컨셉을 지원하지 않기 때문이다

## 반복 가능한 레인지 생성하기

처음값부터 마지막값까지 반복하는 수열생성기 만들기
객체 인터페이스를 가진 반복자 클래스가 필요하다

### How to do it

```cpp
template<typename T>
class Seq {
    T start_{};
    T end_{};

public:
    Seq(T start, T end) : start_{ start }, end_{ end } {}

    class iterator {
        T value_{};
    public:
        explicit iterator(T position = 0) : value_{position} {}

        T operator*() const { return value_; }


		// 레인지 기반 for 반복문을 사용하기 위한 조건
        iterator& operator++() {
            ++value_;
            return *this;
        }

        bool operator!=(const iterator& other) const {
            return value_ != other.value_;
        }
    };

    iterator begin() const { return iterator{start_}; }
    iterator end() const { return iterator{end_}; }
};
```

- 일반적으로 iterator 클래스는 컨테이너 클래스의 public 영역에 정의된다 이는 멤버 클래스 중첩클래스라고 한다

```cpp
int main() {
    Seq<int> r{ 100, 110 };

    for (auto v : r) {
        cout << format("{} ", v);
    }
    cout << '\n';
}
```

### How it works

위에 레인지 기반 for반복문을 보면 for 반복문에서 동작하기 위해서는 아래 요구사항이 필요하다

- begin(), end() 반복자
- 반복자에서 같지 않음 비교 != 연산자 제공
- 반복자에서 전위 증가 ++ 연산자 제공
- 반복자에서 역참조* 연산자 제공

### There's more

iterator 타입을 컨테이너에 종속되게 만들기

- 반복자 타입을 컨테이너 클래스 안에 품어서 컨테이너::iterator 형태로 사용하게 함

`Seq<int>::iterator it = r.begin();`

## 반복자를 STL 반복자 특성과 호환되게 하기

많은 STL 알고리즘은 반복자가 특정 속성에 대해 충족할 것을 요구한다 하지만 이 요구사항은 일관성이 없다

```cpp
Seq<int> r{ 100, 110 };
auto [min_it, max_it] = minmax_element(r.begin(), r.end());
cout << format("{} - {}\n", *min_it, *max_it);
```

우리가 만든 반복자가 알고리즘과 호환을 위한 요구사항을 충족하지 않았다

### How to do it

반복자는 최소한 순방향 반복자의 요구사항을 충족해야한다

```cpp
bool operator==(const iterator& other) const noexcept {
return value_ == other.value_;
}
```

이렇게만 해도 컴파일되고 실행되지만 Clang에서는 오류가 생긴다

- 반복자의 특성을 설정해야 한다는 오류

```cpp
using iterator_concept  = std::forward_iterator_tag;
using iterator_category = std::forward_iterator_tag;
using value_type        = std::remove_cv_t<T>;
using difference_type   = std::ptrdiff_t;
using pointer           = const T*;
using reference         = const T&;
```

특성 설정

### How it works

```cpp
using iterator_concept  = std::forward_iterator_tag;
using iterator_category = std::forward_iterator_tag;
```

컨셉과 카테고리 이 반복자가 순방향 반복자 명세를 따르고 있다는 의미

```cpp
using value_type        = std::remove_cv_t<T>; // const 한정자가 제거된 타입
using difference_type   = std::ptrdiff_t;      // 포인터 차이를 나타내는 특수 타입
using pointer           = const T*;            // const로 한정된 포인터와 참조타입
using reference         = const T&;
```

이렇게 타입 별칭을 정의하는 것은 대부분의 반복자의 기본 요구사항

### There's more

이러한 특성들을 정의하면 컨셉으로 제한된 템플릿을 반복자와 함께 사용할 수 있다는 점에 주목할만하다

```cpp
template<typename T>
requires std::forward_iterator<typename T::iterator>
void printc(const T & c)
{
	for(auto v : c)
	{
		cout << foramt("{} ", v);
	}
	cout << '\n';
}
```

이 함수는 forward_iterator 컨셉을 만족해야지 수열을 출력할 수 있다
C++20에서는 **콘셉트**로 "내 컨테이너가 표준이 요구하는 조건을 갖췄는지" 컴파일 시점에 검사할 수 있고, **`ranges::` 알고리즘**으로 `begin()/end()` 없이 컨테이너만 넘겨 더 편하게 쓸 수 있으며, **`static_assert`** 로 그 호환성을 코드에 박아두고 자동 검증할 수 있다

## 반복자 어댑터를 사용하여 STL 컨테이너 채우기

반복자 어댑터는 반복자처럼 보이지만 다른 기능을 수행하는 클래스다

반복자 어댑터는 세가지로 분류될 수 있다

- 삽입 반복자 혹은 삽입자 - 컨테이너에 요소를 넣는데 사용한다
- 스트림 반복자 - 스트림을 읽거나 쓴다
- 역방향 반복자 - 반복자의 방향을 역전 시킨다

### How to do it

```cpp
void printc(const auto & v, const string_view s = "") {
    if(s.size()) cout << format("{}: ", s);
    for(auto e : v) cout << format("{} ", e);
    cout << '\n';
}
```

```cpp
int main() {
    deque<int> d1{ 1, 2, 3, 4, 5 };
    deque<int> d2(d1.size());

    copy(d1.begin(), d1.end(), d2.begin());
    printc(d1);
    printc(d2, "d2 after copy");
}
```

메모리가 할당되지 않은 벡터에서 이 함수를 실행하면 세그멘테이션 폴트 오류가 발생한다
copy함수에서 반복자가 유효한지 검사하지 않기 때문에

요소를 복사하면서 컨테이너 끝에 추가할 때는 push_back()을 호출하는 알고리즘이 훨씬 유용하다

이 때 `back_inserter` 삽입 반복자 어댑터를 사용하면 좋다

```cpp
copy(d1.begin(), d1.end(), back_inserter(d2));
printc(d2, "d2 after back_inserter");
```

front_inserter 어댑터로 컨테이너 앞에 넣을 수 있다

```cpp
deque<int> d3{ 47, 73, 114, 138, 54 };
copy(d3.begin(), d3.end(), front_inserter(d2));
printc(d2, "d2 after front_inserter");
```

가운데 넣고 싶으면 `inserter`을 호출하면 된다

```cpp
auto it2{ d2.begin() + 2};
copy(d1.begin(), d1.end(), inserter(d2, it2));
printc(d2, "d2 after middle insert");
```

스트림 반복자

```cpp
cout << "ostream_iterator: ";
copy(d1.begin(), d1.end(), ostream_iterator<int>(cout));
cout << '\n';

// ostream_iterator: 12345
```

istream_iterator

- 스트림이 전달되지 않을 경우 기본적으로 end 반복자를 반환한다

```cpp
vector<string> vs{};
copy(istream_iterator<string>(cin), istream_iterator<string>(), back_inserter(vs));
printc(vs, "vs2 from istream");
```

역방향 어댑터

```cpp
cout << "Reverse iterator: ";
for(auto it = d1.rbegin(); it != d1.rend(); ++it) {
  cout << format("{} ", *it);
}
cout << '\n';
// 5 4 3 2 1 
```

### How it works

반복자 어댑터는 현재 컨테이너를 래핑하여 동작한다

```cpp
copy(d1.begin(), d1.end(), back_inserter(d2));
```

어댑터는 반복자를 흉내내는 객체(back_inserter)를 반환한다 그 객체는 값이 반복자에 할당될 때 컨테이너 객체의 push_back() 메서드를 호출한다

istream_iterator()은 센티널을 필요로 한다 istream_iterator을 인자없이 호출하면 센티널이 생성된다 그래서 일반 컨테이너처럼 순회를 할 수 있다

```cpp
auto it = istream_adapter<string>(cin);
auto it_end = istream_adapter<string>(); // 센티널 생성
```

## 반복자로 생성기 만들기

생성기는 자체적으로 값의 수열을 생성하는 반복자로 컨테이너를 사용하지 않는다

### How to do it

```cpp
#include <format>
#include <iostream>
#include <string_view>
#include <algorithm>
#include <ranges>

using std::format;
using std::cout;
using std::string_view;

namespace ranges = std::ranges;

void printc(const auto & v, const string_view s = "") {
    if(s.size()) cout << format("{}: ", s);
    for(auto e : v) cout << format("{} ", e);
    cout << '\n';
}

class fib_generator {
    using fib_t = unsigned long;

    fib_t stop_{};
    fib_t count_ { 0 };
    fib_t a_ { 0 };
    fib_t b_ { 1 };

    constexpr void do_fib() {
        const fib_t old_b = b_;
        b_ += a_;
        a_  = old_b;
    }

public:
	// 순방향 반복자를 위한 연산자 오버로드
    using iterator_concept  = std::forward_iterator_tag;
    using iterator_category = std::forward_iterator_tag;
    using value_type        = std::remove_cv_t<fib_t>;
    using difference_type   = std::ptrdiff_t;
    using pointer           = const fib_t*;
    using reference         = const fib_t&;

    explicit fib_generator(fib_t stop = 0) : stop_{ stop } {}

    fib_t operator*() const { return b_; }

    constexpr fib_generator& operator++() {
        do_fib();
        ++count_;
        return *this;
    }

    fib_generator operator++(int) {
        auto temp{ *this };
        ++*this;
        return temp; 
    }

    bool operator!=(const fib_generator &o) const {
        return count_ != o.count_; 
    }

    bool operator==(const fib_generator&o) const { 
        return count_ == o.count_; 
    }

    const fib_generator& begin() const { return *this; }

    const fib_generator end() const { 
        auto sentinel = fib_generator();
        sentinel.count_ = stop_;
        return sentinel;
    }

    fib_t size() { return stop_; }

};

int main() {
    printc(fib_generator(10));

    fib_generator fib(10);
    auto x = ranges::views::transform(fib, [](unsigned long x){ return x * x; });
    printc(x, "squared:");
}
```

### How it works

fib_generator 클래스는 순방향 반복자로 동작하며 여러가지 인터페이스를 제공하며 레인지 기반의 for 반복문에서도 동작할 수 있게 한다

### There's more

생성기가 algorithm 라이브러리와 동작하기를 원한다면 traits 별칭을 제공을 해야한다(?)

## 역방향 반복자 어댑터를 사용하여 역방향으로 반복하기

반복자 클래스의 방향을 역전하는 추상화이다 양방향 반복자를 필요로 한다

### How to do it

STL에 있는 대부분의 양방향 컨테이너는 역방향 반복자 어댑터를 포함한다

순방향 반복자

```cpp
auto it = std::begin(array);
auto end_it = std::end(array);
while(it != end_it)
{
	cout << format("{} ", *it++);
}
```

역방향 반복자

```cpp
auto it = std::rbegin(array);
auto end_it = std::rend(array);
while(it != end_it)
{
	cout << format("{} ", *it++);
}
```

### How it works

일반적인 반복자 클래스는 첫번째 요소를 가리키는 begin()와 마지막 요소의 다음을 가리키는 end() 반복자가 있고 순회를 할 때는 begin() 반복자를 ++연산자로 증가시키며 end()에 도달하게된다
역방향은 begin() 반복자가 마지막요소를 가리키고 end() 반복자가 첫번째 요소 이전을 가리키고 -- 연산자로 감소한다

## 센티널을 넣어 길이를 알 수 없는 객체 반복하기

반복문에서 문자열을 다루려면 반복자와 센티널이 필요하다

### How to do it

레인지 기반의 for반복문에 필요한 최소한의 요구사항

```cpp

#include <format>
#include <iostream>
#include <vector>

using std::format;
using std::cout;
using std::string_view;
using std::vector;

using sentinel_t = const char;
constexpr sentinel_t nullchar = '\0';

class cstr_it {
    const char *s{};

public:
    explicit cstr_it(const char *str) : s{str} {}

    char operator*() const { return *s; }

    cstr_it& operator++() {
        ++s;
        return *this;
    }

    bool operator!=(sentinel_t) const {
        return s != nullptr && *s != nullchar;
    }

    cstr_it begin() const { return *this; }
    sentinel_t end() const { return nullchar; }
};
```

### How it works

반복자 클래스의 센티널은 end()함수에서 센티널값으로 null 종결자를 반환한다
그 다음에 비교연산자를 사용하여 이를 검사할 수 있다

```cpp
bool operator!=(sentinel_t) const {
  return s != nullptr && *s != nullchar;
}
```

## zip 반복자 어댑터 만들기

zip 연산은 두개의 입력 수열을 받아 각 위치에서 두 입력의 값을 쌍으로 반환한다

### How to do it

이렇게 반복자 대신 zip_iterator를 사용할 수 있다

```cpp
int main() {
    vector<std::string> vec_a {"Bob", "John", "Joni"};
    vector<std::string> vec_b {"Dylan", "Williams", "Mitchell"};

    cout << "zipped: ";
    for(auto [a, b] : zip_iterator(vec_a, vec_b)) {
        cout << format("[{}, {}] ", a, b);
    }
    cout << '\n';
}
```

편의를 위한 타입 별칭

```cpp
template<typename T>
class zip_iterator {
    using val_t = typename T::value_type;
    using ret_t = std::pair<val_t, val_t>;
    using it_t = typename T::iterator;
```

대상 컨테이너의 begin(), end() 반복자의 복사본만 저장

```cpp
    it_t ita_{};
    it_t itb_{};

    // for begin() and end() objects
    it_t ita_begin_{};
    it_t itb_begin_{};
    it_t ita_end_{};
    it_t itb_end_{};
```

나중에 begin(), end() 반복자를 위한 어댑터 객체를 생성하는데 사용된다

```cpp
    zip_iterator(it_t ita, it_t itb) : ita_{ita}, itb_{itb} {}
```

반복자 특성 타입의 정의

```cpp
public:
    using iterator_concept  = std::forward_iterator_tag;
    using iterator_category = std::forward_iterator_tag;
    using value_type        = std::pair<val_t, val_t>;
    using difference_type   = long int;
    using pointer           = const val_t*;
    using reference         = const val_t&;
```

생성자는 모든 private 반복자 변수를 설정

```cpp
    zip_iterator(T& a, T& b) : 
        ita_{a.begin()},
        itb_{b.begin()},
        ita_begin_{ita_},
        itb_begin_{itb_},
        ita_end_{a.end()},
        itb_end_{b.end()}
    {}
```

순방향 반복자로 동작하는 최소한의 연산자 오버로드

```cpp
zip_iterator& operator++() {
  ++ita_;
  ++itb_;
  return *this;
}

bool operator==(const zip_iterator& o) const {
  return ita_ == o.ita_ || itb_ == o.itb_;
}

bool operator!=(const zip_iterator& o) const {
  return !operator==(o);
}

ret_t operator*() const {
  return { *ita_, *itb_ };
}
```

## 임의 접근 반복자 만들기

### How to do it

반복자를 위한 컨테이너

```cpp
template<typename T>
class Container {
    std::unique_ptr<T[]> c_{}; // 데이터 관리
    size_t n_elements_{};       // 컨테이너 크기
```

```cpp
// 생성자
Container(initializer_list<T> l) : n_elements_{l.size()} {
  c_ = std::make_unique<T[]>(n_elements_);
  size_t index{0};
  for(T e : l) {
	c_[index++] = e;
  }
}

// 요소를 채우지 않은 공간
Container(size_t sz) : n_elements_{sz} {
  c_ = std::make_unique<T[]>(n_elements_);
}

// 요소의 개수
size_t size() const {
  return n_elements_;
}

// index의 요소 반환
const T& operator[](const size_t index) const {
  return c_[index];
}

// 경계 검사 후 인덱스의 요소 반환
T& at(const size_t index) const {
  if(index > n_elements_ - 1) {
	throw std::out_of_range("Container::at(): index out of range");
  }
  return c_[index];
}

// 컨테이너 데이터의 주소로 반복자의 생성자를 호출
iterator begin() const { return iterator(c_.get()); }
iterator end() const { return iterator(c_.get() + n_elements_); }
```
