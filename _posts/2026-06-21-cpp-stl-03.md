## STL 컨테이너 타입에 대한 빠른 개요

### 순차 컨테이너

요소들이 순차적으로 배열된 인터페이스를 제공한다.

- **array** — 고정 크기 컨테이너. 연속된 공간에 저장되며, 한번 할당되면 크기를 바꿀 수 없다. 가장 단순하고 빠르다.
- **vector** — 크기를 바꿀 수 있는 배열. 요소들이 연속된 공간에 저장된다. 크기를 바꾸면 메모리 재할당과 데이터 이동 비용이 발생할 수 있어, 이를 줄이려고 여분의 공간을 미리 확보한다. 마지막이 아닌 위치에 삽입·삭제하면 연속성을 유지하기 위해 요소들의 재배열이 일어난다.
- **list** — 요소를 O(1)에 삽입·삭제할 수 있는 이중 연결 리스트. 단, 순회할 때는 O(n)이 든다. 단일 연결 리스트인 `forward_list`도 있다.
- **deque** — 양쪽 끝에서 확장·축소가 가능한 이중 끝 큐(double-ended queue). 벡터처럼 임의 접근을 허용하지만 연속된 공간을 보장하지 않는다.

### 연관 컨테이너

각 요소가 키를 가진다.

- **set** — 각 요소가 스스로 키 역할을 하는 컨테이너. 요소들은 이진 트리로 정렬된다.
- **multiset** — 중복을 허용하는 set.
- **unordered_set** — 순서대로 반복하지 않는 set. 요소들은 특정 순서가 아니라 빠른 접근을 위해 해시값으로 관리된다.
- **unordered_multiset** — 중복 키를 허용하는 unordered_set.
- **map** — 키-값 쌍으로 이루어진 컨테이너. 키는 고유하며 특정 값에 매핑된다. 반복자는 키의 정렬 순서를 따른다.
- **multimap** — 중복 키를 허용하는 map.
- **unordered_map** — 반복자가 순서를 따르지 않는 map.
- **unordered_multimap** — 중복 키를 허용하는 unordered_map.

### 컨테이너 어댑터

하위 컨테이너를 캡슐화하는 클래스. 하위 컨테이너의 요소에 접근하는 특정 멤버 함수들의 집합을 제공한다.

- **stack** — LIFO(Last-In, First-Out) 인터페이스를 제공한다. 컨테이너 한쪽 끝에서만 요소를 추가·제거할 수 있다. 하위 컨테이너로 vector, deque, list 중 하나를 지정할 수 있고 기본값은 deque이다. (stack은 왜 셋 중 하나를 고르게 했을까?)
- **queue** — FIFO(First-In, First-Out) 인터페이스를 제공한다. 한쪽 끝에서 추가하고 다른 쪽에서 제거한다. 하위 컨테이너는 deque 또는 list이며, 지정하지 않으면 기본값은 deque이다.
- **priority_queue** — strict weak ordering에 따라 가장 큰 요소를 맨 위에 유지한다. 가장 큰 요소 접근은 O(1)이고, 삽입과 제거는 O(log n)에 수행된다. 하위 컨테이너는 vector 또는 deque이며 기본값은 vector이다.

## 단일 제거 함수를 사용하여 컨테이너의 값 제거하기

C++20 이전에는 STL 컨테이너에서 효율적으로 요소를 삭제하기 위해 erase-remove 관용구가 쓰였다.

```cpp
template<typename Tc, typename Tv>
void remove_value(Tc& c, const Tv v) {
    auto remove_it = std::remove(c.begin(), c.end(), v);
    c.erase(remove_it, c.end());
}
```

`std::remove`는 `<algorithm>`에 있으며, 컨테이너에서 특정 값을 찾아 제거하면서 뒤의 요소들을 하나씩 앞으로 당긴다(이때 크기는 변하지 않는다). 범위 끝까지 이동한 뒤 남은 부분을 `erase`로 잘라낸다.

C++20부터는 `std::erase`를 사용하면 이 과정을 한 번에 처리할 수 있다.

### How to do it

단일 제거 함수는 두 가지 형태다.

```cpp
std::erase(container, value);        // erase
std::erase_if(container, predicate); // erase-if
```

- `erase` — array를 제외한 모든 컨테이너에서 사용 가능.
- `erase_if` — 모든 컨테이너에서 사용 가능. 연관 컨테이너와 그들의 다중 키·비정렬 변형에서도 동작한다.

### How it works...

erase-remove 관용구와 동일한 작업을 더 간결하게 처리해 준다.

## 정렬되지 않은 벡터에서 상수 시간으로 값 제거하기

벡터 중간 요소를 제거하면 뒤 요소를 앞으로 당겨야 해서 선형 시간(O(n))이 든다. 순서가 중요하지 않다면 상수 시간(O(1))으로 줄일 수 있다.

### How to do it

끝에서 제거하는 게 빠르다는 점을 이용한다.

1. 인덱스가 범위 안인지 확인
2. 마지막 요소를 그 자리로 이동
3. `pop_back()`으로 크기 축소

```cpp
#include <iostream>
#include <format>
#include <vector>
#include <algorithm>

using std::cout;
using std::format;
using std::vector;
using std::move;

// 인덱스를 사용하는 경우
template<typename T>
void quick_delete(T& v, size_t idx) {
    if (idx < v.size()) {
        v[idx] = move(v.back());
        v.pop_back();
    }
}

// 인덱스 대신 반복자를 사용하는 경우
template<typename T>
void quick_delete(T& v, typename T::iterator it) {
    if (it < v.end()) {
        *it = move(v.back());
        v.pop_back();
    }
}

```

### How it works...

마지막 요소를 빈자리로 복사가 아닌 **이동(move)** 시키고, `pop_back()`으로 끝을 줄인다. `pop_back()`은 `end()` 반복자만 바꾸므로 O(1)이다. 
벡터 끝에서 요소를 제거하는게 비용이 특히 낮다는 점을 이용한 순서를 지킬 필요가 없을 때 쓰는 기법.

## 벡터의 요소에 직접적이고 안전하게 접근하기

벡터는 STL 클래스 중에 가장 널리 사용되는 클래스이며 array만큼 편리하면서 휠씬 더 강력하고 유연하다
보통 벡터 요소는 `[]`로 접근한다.

```cpp
auto& i = v[2];
```

같은 일을 하는 멤버 함수 `at()`도 있다.

```cpp
auto& i = v.at(2);
```

차이는 하나다. `at()`은 경계 검사를 하고, `[]`는 일부러 하지 않는다.
이는 원래 C 배열과 호환성을 유지하기 위함이다

### How to do it

벡터의 가장 큰 문제는 끝을 넘는 위치에도 경고 없이 값을 쓸 수 있다는 것이다.

```cpp
vector v{ 19, 71, 47, 192, 4004 };
v[5] = 10;
auto& i = v[5];
cout << format("element is {}\n", i);
```

오류도 크래시도 없이 조용히 통과한다. 이게 위험하다. 경계 밖 메모리 접근은 보안 취약점의 단골 원인이다.
이 문제를 해결하려면 경계 검사를 하는 `at()`을 사용하면 된다

```cpp
v.at(5) = 10;
auto& i = v.at(5);
cout << format("element is {}\n", i);
```

이러면 런타임 에러를 던진다.

### How it works...

`[]`는 검사가 없어 반복문이 많은 코드에서 살짝 빠를 수 있다. 하지만 그 차이는 CPU 사이클 몇 개뿐이라, 안전성을 얻는 쪽이 훨씬 이득이다. vector·array·deque에서 쓸 수 있다.

### There's more

크래시 대신 예외로 처리할 수도 있다.

```cpp
int main() {
    vector v{ 19, 71, 47, 192, 4004 };
    try {
        v.at(5) = 2001;
    }
    catch (const std::out_of_range& e) {
        cout << format("Ouch!\n{}\n", e.what());
    }
    cout << format("end element is {}\n", v.back());

    return 0;
}
```

## 벡터의 요소들의 정렬 유지하기

벡터는 정렬을 알아서 유지해 주지 않는다. set·map은 정렬되지만 임의 접근이 안 된다. 그래서 삽입할 때마다 올바른 위치에 넣어 정렬을 유지한다.

### How to do it

타입 별칭부터 둔다. (별칭을 쓰면 벡터의 세부 타입이 중요하지 않다는 걸 드러낼 수 있다.)

```cpp
using Vstr = vector<string>;
```

지원 함수 — 출력, 그리고 정렬 여부 확인.

```cpp
void printv(const auto& v) {
    for (auto& e : v) cout << format("{} ", e);
    cout << "\n";
}

// is_sorted 함수의 레인지 버전을 사용해
// 벡터가 정렬되었는지 판단한다.
void psorted(const Vstr& v) {
    if (std::ranges::is_sorted(v)) cout << "sorted: ";
    else cout << "unsorted: ";
    printv(v);
}
```

핵심은 `insert_sorted`. `lower_bound()`로 들어갈 위치를 찾아 거기에 `insert()` 한다.

```cpp
void insert_sorted(Vstr& v, const string& s) {
    const auto pos{ std::ranges::lower_bound(v, s) };
    v.insert(pos, s);
}
```

전체 예제.

```cpp
#include <iostream>
#include <format>
#include <vector>
#include <algorithm>
#include <string>

using std::cout;
using std::format;
using std::vector;
using std::string;

using Vstr = vector<string>;

void printv(const auto& v) {
    for (auto& e : v) cout << format("{} ", e);
    cout << "\n";
}

void psorted(const Vstr& v) {
    if (std::ranges::is_sorted(v)) cout << "sorted: ";
    else cout << "unsorted: ";
    printv(v);
}

void insert_sorted(Vstr& v, const string& s) {
    const auto pos{ std::ranges::lower_bound(v, s) };
    v.insert(pos, s);
}

int main() {
    Vstr v{
        "Miles",
        "Hendrix",
        "Beatles",
        "Zappa",
        "Shostakovich"
    };

    // sort 알고리즘의 레인지 버전으로 벡터 정렬
    std::ranges::sort(v);
    psorted(v);

    insert_sorted(v, "Ella");
    insert_sorted(v, "Stones");
    psorted(v);

    return 0;
}
```

### How it works...

`lower_bound()`는 인수보다 작지 않은 첫 요소의 반복자를 돌려준다. 그 위치에 넣으면 정렬이 그대로 유지된다.

### There's more

템플릿으로 일반화할 수 있다.

```cpp
template<typename C, typename E>
void insert_sorted(C& c, const E& e) {
    const auto pos{ std::ranges::lower_bound(c, e) };
    c.insert(pos, e);
}
```

`std::sort()`는 임의 접근 컨테이너만 되지만, 이 버전은 set·deque·list에서도 쓸 수 있다.

## 맵에 요소를 효율적으로 삽입하기

map에 요소를 넣는 방법은 셋이다.

```cpp
map<string, string> m;

// 1. [] 연산자로 추가
m["Miles"] = "Trumpet";

// 2. insert 메서드로 추가
m.insert(pair<string, string>("Hendrix", "Guitar"));

// 3. emplace() 메서드로 추가
m.emplace("Krupa", "Drums");
```

`emplace()`는 완벽한 전달(perfect forwarding)로 컨테이너 안에서 요소를 바로 생성해 유리하다. 하지만 키가 중복이라 실패할 때조차 생성자 호출·메모리 할당·임시 객체 폐기를 다 한다. C++17에 추가된 `try_emplace()`는 이 낭비를 막는다.

### How to do it

`try_emplace()`는 페이로드 객체를 **필요할 때까지** 만들지 않는다. 페이로드가 클수록 이득이 크다.

```cpp
struct BigThing {
    string v_;
    BigThing(const char* v) : v_(v) {
        cout << format("BigThing constructed {}\n", v_);
    }
};

// 함수에 집중할 수 있도록 가독성을 높이는 별칭
using Mymap = map<string, BigThing>;
```

생성될 때 메시지를 찍는 `BigThing`으로 차이를 확인한다.

```cpp
// 맵에 추가되는 요소들을 추적하기 위한 출력 함수
void printm(Mymap& m) {
    for (auto& [k, v] : m) {
        cout << format("[{} : {}] ", k, v.v_);
    }
    cout << "\n";
}
```

중복 키를 넣어 보면 차이가 드러난다.

```cpp
#include <format>
#include <iostream>
#include <map>
#include <unordered_map>
#include <string>
#include <algorithm>

using std::format;
using std::cout;
using std::map;
using std::unordered_map;
using std::string;

struct BigThing {
    string v_;
    BigThing(const char * v) : v_(v) {
        cout << format("BigThing constructed {}\n", v_);
    }
};

using Mymap = map<string, BigThing>;   // convenience alias

void printm(Mymap& m) {
    for(auto& [k, v] : m) {
        cout << format("[{}:{}] ", k, v.v_);
    }
    cout << "\n";
}

int main() {
    Mymap m;

    m.try_emplace("Miles", "Trumpet");
    m.try_emplace("Hendrix", "Guitar");
    m.try_emplace("Krupa", "Drums");
    m.try_emplace("Zappa", "Guitar");
    m.try_emplace("Liszt", "Piano");
    printm(m);

    cout << "\n";
    cout << "emplace(Hendrix)\n";
    m.emplace("Hendrix", "Singer");
    cout << "try_emplace(Zappa)\n";
    m.try_emplace("Zappa", "Composer");
    printm(m);

    const char * key{"Zappa"};
    const char * payload{"Composer"};
    if(auto [it, success] = m.try_emplace(key, payload); !success) {
        cout << "update\n";
        it->second = payload;
    }
    printm(m);
}
```

`emplace`는 중복 키 추가에 실패했지만 페이로드를 생성했고 `try_emplace`는 실패하면 페이로드를 생성하지 않는다.

### How it works...

시그니처가 `emplace()`와 거의 같아서 기존 코드를 바꾸기 쉽다.

```cpp
// try_emplace의 시그니처
pair<iterator, bool> try_emplace(const Key& k, Args&&... args);

// emplace의 시그니처
pair<iterator, bool> emplace(Args&&... args);
```

반환값도 `emplace()`처럼 반복자와 bool의 쌍이다.

```cpp
const char* key{ "Zappa" };
const char* payload{ "Composer" };
if (auto [it, success] = m.try_emplace(key, payload); !success) {
    cout << "update\n";
    it->second = payload;
}
printm(m);
```
`try_emplace`은 unordered_map에서도 동작을 한다. 
`try_emplace`은 맵에 요소를 추가할 때만 페이로드 객체를 생성해서 런타임에 상당한 자원을 아낄 수 있다는 것이 장점이다
항상 `try_emplace`을 `emplace`보다 먼저 고려하자


## 맵 항목의 키를 효율적으로 변경하기

map의 키는 const로 지정되기 때문에 바꿀 수 없다. 직접 바꾸려 하면 컴파일 오류가 난다.

```cpp
map<int, string> mymap{
    {1, "foo"}, {2, "bar"}, {3, "baz"}
};
auto it = mymap.begin();
it->first = 47; // error: assignment of read-only member...
```

키를 바꾸려면 C++17에서 추가된 `extract()`를 사용해서 변경할 수 있다
`extract()`는 map 클래스 및 그 파생 클래스의 멤법 함수이려 페이로드에 영향을 주지 않고(?) map의 요소를 추출 할 수 있게 해준다

### How to do it

순위를 맞바꾸는 경주 예제다.

```cpp
#include <format>
#include <iostream>
#include <map>
#include <string>

using std::format;
using std::cout;
using std::map;
using std::string;
using std::swap;

using Racermap = map<unsigned int, string>;

void printm(const Racermap &m)
{
    cout << "Rank:\n";
    for (const auto& [rank, racer] : m) {
        cout << format("{}:{}\n", rank, racer);
    }
}

template<typename M, typename K>
bool node_swap(M & m, K k1, K k2) {
    auto node1{ m.extract(k1) };
    auto node2{ m.extract(k2) };
    if(node1.empty() || node2.empty()) {
        return false;
    }
    swap(node1.key(), node2.key());
    m.insert(move(node1));
    m.insert(move(node2));
    return true;
}

int main() {
    Racermap racers {
        {1, "Mario"}, {2, "Luigi"}, {3, "Bowser"},
        {4, "Peach"}, {5, "Donkey Kong Jr."}
    };
    printm(racers);

    node_swap(racers, 3, 5);
    printm(racers);
}
```

`extract()`로 꺼낸 요소를 **노드(node)**라고 한다. C++17에서 추가된 개념, 컨테이너에서 링크가 끊긴 노드 핸들이 반환되고, `key()`로 그 키에 쓸 수 있다.

### How it works...

`extract()`는 노드를 지우지 않고 연관만 끊어 `node_handle`로 돌려준다. 즉 데이터는 그대로 둔 채 컨테이너에서 노드만 떼어낸다. `key()`로 그 키를 자유롭게 바꾼 뒤 다시 `insert()` 하면 된다.

### There's more

**`extract()`와 node_handle 유의점**

키가 없으면 빈 노드 핸들이 오니 확인해야 한다.

```cpp
auto node{ m.extract(key) };
if (node.empty()) {
    // 노드 핸들이 비어 있는 상태
}
```

오버로드는 두 가지다.

```cpp
node_type extract(const key_type& x);
node_type extract(const_iterator position);
```

리터럴에서는 참조를 만들 수 없으니, `extract(1)` 같은 호출은 크래시가 날 수 있다.

이미 있는 키 값으로 바꿔 넣으면 삽입이 실패한다.

```cpp
auto node_x{ racers.extract(racers.begin()) };
node_x.key() = 5;
auto status = racers.insert(move(node_x));
if (!status.inserted) {
    cout << format("insert failed, dup key: {}", status.position->second);
    exit(1);
}
```

이미 존재하는 값으로 키를 할당한 뒤 삽입하면 실패하고, `if` 블록에서 `format()`으로 충돌한 키의 값을 출력한다.

## unordered_map에 사용자 정의 타입의 키 사용하기

정렬 map의 키는 `<` 연산자가 필요하다. 정렬이 안 되는 사용자 정의 타입을 키로 쓰려면 `unordered_map`을 쓰면 된다.

### How to do it

두 가지가 필요하다.

1. `==` 연산자 정의

```cpp
bool operator==(const Coord& lhs, const Coord& rhs) {
    return lhs.x == rhs.x && lhs.y == rhs.y;
}
```

2. `std::hash` 특수화

```cpp
namespace std {
    template<>
    struct hash<Coord> {
        size_t operator()(const Coord& c) const {
            return static_cast<size_t>(c.x) + static_cast<size_t>(c.y);
        }
    };
}
```

전체 코드.

```cpp
#include <format>
#include <iostream>
#include <unordered_map>
#include <string>

using std::format;
using std::cout;
using std::unordered_map;

struct Coord {
    int x{};
    int y{};
};

using Coordmap = unordered_map<Coord, int>;

bool operator==(const Coord& lhs, const Coord& rhs) {
    return lhs.x == rhs.x && lhs.y == rhs.y;
}

namespace std {
    template<>
    struct hash<Coord> {
        size_t operator()(const Coord& c) const {
            return static_cast<size_t>(c.x)
                 + static_cast<size_t>(c.y);
        }
    };
}

void print_Coordmap(const Coordmap& m) {
    for (const auto& [key, value] : m) {
        cout << format("{{ ({}, {}): {} }} ",
            key.x, key.y, value);
    }
    cout << '\n';
}

int main() {
    Coordmap m {
        { {0, 0}, 1 },
        { {0, 1}, 2 },
        { {2, 1}, 3 } 
    };
    print_Coordmap(m);

    Coord k{ 0, 1 };
    cout << format("{{ ({}, {}): {} }}\n",
        k.x, k.y, m.at(k));
}
```

### How it works...

`unordered_map`은 키를 찾을 때 **해시 클래스**를 쓴다. 기본 템플릿은 이렇게 생겼다.

```cpp
template<
    class Key,
    class T,
    class Hash = std::hash<Key>,
    class KeyEqual = std::equal_to<Key>,
    class Allocator = std::allocator<std::pair<const Key, T>>
> class unordered_map;
```

`Hash`·`KeyEqual`·`Allocator`에 기본값이 있어 보통은 생략한다. `std::hash`는 기본 타입엔 특수화가 들어 있지만, 사용자 정의 타입엔 직접 만들어 줘야 한다.

```cpp
std::unordered_map<Coord, value_type, my_hash_type> my_map;
```

## set으로 사용자 입력을 정렬하고 필터링하기

set으로 입력에서 중복을 걸러 보자.

### How to do it

표준 입력에서 단어를 받는다.

```cpp
using input_it = istream_iterator<string>;

// inserter 함수와 함께 사용할 반복자 쌍
input_it it{ cin };
input_it end{};
```

`end`는 기본 생성자로 만든 **스트림 종료 반복자**다. 입력이 끝나면 cin 반복자가 이것과 같아진다. `inserter()`로 set에 넣는다.

```cpp
#include <format>
#include <iostream>
#include <set>
#include <string>
#include <iterator>
#include <algorithm>

using std::format;
using std::cout;
using std::set;
using std::string;
using std::istream_iterator;
using std::cin;
using std::copy;
using std::inserter;

using input_it = istream_iterator<string>;

int main() {
    set<string> words;

    input_it it{ cin };
    input_it end{};

    copy(it, end, inserter(words, words.end()));
    
    for(const string & w : words) {
        cout << format("{} ", w);
    }
    cout << '\n';
}
```

### How it works...

`istream_iterator`는 스트림에서 읽는 입력 반복자다. 역참조할 때마다 단어 하나가 나온다. 종료 반복자는 기본 생성자로 만든다.

```cpp
istream_iterator<string> end{};
```

입력이 끝나면 둘이 같아져서 `copy()`의 반복이 끝난다. `copy(시작, 끝, 대상)`에 `inserter()`를 조합하면 스트림을 set으로 바로 복사할 수 있다. `inserter()`는 컨테이너와 삽입 지점을 받아 알맞은 `insert_iterator`를 돌려준다.

## deque로 단순한 RPN 계산기 만들기

**RPN**은 스택 기반 후위 표기법 계산기다. `1 2 +`처럼 피연산자 뒤에 연산자를 둔다. 연산자가 즉시 처리돼서 `=` 키도 필요 없다.

### How to do it

stack 대신 deque를 쓰는 이유: stack은 어차피 deque를 기본 저장소로 쓰는 어댑터이고, deque는 반복자로 순회·출력까지 돼서 종이 테이프 계산기처럼 중간 과정을 보여줄 수 있다.

```cpp
class RPN {
    // RPN 스택을 저장하는 공간
    deque<double> deq_{};
    // 반환값·비교에 사용할 상수
    constexpr static double zero_{ 0.0 };
    // 0으로 나누기 오류를 처리하는 데 사용
    constexpr static double inf_{ std::numeric_limits<double>::infinity() };
    // public 및 private 멤버가 여기에 위치
};
```

상수는 `constexpr static`이라 인스턴스마다 공간을 먹지 않고, deque가 자원을 알아서 관리하니 생성자·소멸자도 필요 없다.

주요 멤버는 이렇다.

- `op()` — 진입점. 숫자면 스택에 넣고, 연산자면 `optor()`를 호출한다.
- `pop_get2()` — 피연산자 두 개를 꺼내 쌍으로 반환한다.
- `is_numeric()` — 숫자인지 확인한다(소수점 포함).
- `optor()` — map으로 연산자→람다를 매핑하고, `find()`로 유효성을 확인한 뒤 0 나눗셈을 체크하고 실행한다.

전체 코드.

```cpp
#include <format>
#include <iostream>
#include <stack>
#include <deque>
#include <map>
#include <string>
#include <utility>
#include <cctype>
#include <cmath>
#include <iterator>
#include <limits>

using std::format;
using std::cout;
using std::stack;
using std::deque;
using std::map;
using std::string;
using std::pair;
using std::istream_iterator;
using std::cin;

class RPN {
    deque<double> deq_{};
    constexpr static double zero_{0.0};
    constexpr static double inf_{ std::numeric_limits<double>::infinity() };

public:
    // process an operand/operator
    double op(const string & s) {
        if(is_numeric(s)) {
            double v{stod(s, nullptr)};
            deq_.push_front(v);
            return v;
        }
        else return optor(s);
    }

    // empty the stack
    void clear() {
        deq_.clear();
    }

    // print the stack
    string get_stack_string() const {
        string s{};
        for(auto v : deq_) {
            s += format("{} ", v);
        }
        return s;
    }

private:    // utility functions
    // pop and get two operands
    pair<double, double> pop_get2() {
        if(deq_.size() < 2) return {zero_, zero_};
        double v1{deq_.front()};
        deq_.pop_front();
        double v2{deq_.front()};
        deq_.pop_front();
        return {v2, v1};
    }

    bool is_numeric(const string& s) {
        for(const char c : s) {
            if(c != '.' && !std::isdigit(c)) return false;
        }
        return true;
    }

    // operators 
    double optor(const string& op) {
        map<string, double (*)(double, double)> opmap {
            {"+", [](double l, double r){ return l + r; }},
            {"-", [](double l, double r){ return l - r; }},
            {"*", [](double l, double r){ return l * r; }},
            {"/", [](double l, double r){ return l / r; }},
            {"^", [](double l, double r){ return pow(l, r); }},
            {"%", [](double l, double r){ return fmod(l, r); }}
        };

        if(opmap.find(op) == opmap.end()) return zero_;
        auto [l, r] = pop_get2();

        // don’t divide by zero
        if(op == "/" && r == zero_) deq_.push_front(inf_);
        else deq_.push_front(opmap.at(op)(l, r));
        return deq_.front();
    }
};

int main() {
    RPN rpn;

    for(string o{}; cin >> o; ) {
        rpn.op(o);
        auto stack_str{rpn.get_stack_string()};
        cout << format("{}: {}\n", o, stack_str);
    }
}
```

### How it works...

입력을 판별해 숫자면 스택에 푸시하고, 연산자면 피연산자 두 개를 꺼내 계산한 뒤 다시 푸시한다. 못 알아보는 입력은 그냥 지나간다.

deque를 스택처럼 쓰려고 **한쪽 끝**(여기서는 front)만 사용한다. 연산자는 map으로 유효성 검사와 실행을 한 번에 처리한다.

### There's more

cin 대신 컨테이너에 담은 식을 넘길 수도 있다. (`<vector>` 헤더가 필요하다.)

```cpp
int main() {
    RPN rpn;

    // STL 컨테이너로 계산식을 전달하는 방식
    vector<string> opv{ "9", "6", "*", "2", "3", "*", "+" };
    for (auto o : opv) {
        rpn.op(o);
        auto stack_str{ rpn.get_stack_string() };
        cout << format("{}: {}\n", o, stack_str);
    }

    return 0;
}
```

## map으로 단어 빈도수 계산기 만들기

map의 고유 키를 이용해 텍스트에서 단어별 출현 횟수를 세어 보자.

### How to do it

순서는 이렇다.

1. 파일(또는 cin)에서 텍스트 읽기
2. regex로 단어 분리
3. map으로 빈도 세기
4. 빈도순(같으면 알파벳순)으로 정렬 — sort + vector

정규식은 상수로 둔다. (전역을 어지럽히면 충돌이 나니 이니셜 네임스페이스를 쓴다.)

```cpp
namespace bw {
    constexpr const char* re{ "(\\w+)" };
}
```

`smatch`로 단어를 꺼내 `transform`으로 소문자화하면 The와 the를 같은 단어로 센다. `try_emplace()`로 추가하고 `++count` 한다. 다 세면 정렬을 위해 vector로 옮긴다.

전체 코드 (콘솔 출력이 잘 안 나와 파일에서 읽게 했다).

```cpp
#include <format>
#include <iostream>
#include <algorithm>
#include <map>
#include <vector>
#include <algorithm>
#include <utility>
#include <string>
#include <regex>
#include <cctype>

using std::format;
using std::cout;
using std::string;
using std::map;
using std::vector;
using std::pair;
using std::regex;
using std::sregex_iterator;
using std::smatch;
using std::cin;

namespace ranges = std::ranges;
namespace regex_constants = std::regex_constants;

namespace bw {
    constexpr const char * re{"(\\w+)"};
}

int main() {
    map<string, int> wordmap{};    
    vector<pair<string, int>> wordvec{};
    regex word_re(bw::re);
    size_t total_words{};

    for(string s{}; cin >> s; ) {
        auto words_begin{ sregex_iterator(s.begin(), s.end(), word_re) };
        auto words_end{ sregex_iterator() };

        for(auto r_it{ words_begin }; r_it != words_end; ++r_it) {
            smatch match{ *r_it };
            auto word_str{match.str()};

            ranges::transform(word_str, word_str.begin(),
                [](unsigned char c){ return tolower(c); });

            auto [map_it, result] = wordmap.try_emplace(word_str, 0);
            auto & [w, count] = *map_it;
            ++total_words;
            ++count;
        }
    }

    auto unique_words = wordmap.size();
    wordvec.reserve(unique_words);
    ranges::move(wordmap, back_inserter(wordvec));
    ranges::sort(wordvec, [](const auto& a, const auto& b) { 
        if(a.second != b.second)
            return (a.second > b.second);
        return (a.first < b.first);
    });

    cout << format("total word count: {}\n", total_words);
    cout << format("unique word count: {}\n", unique_words);

    for(int limit{20}; auto& [w, count] : wordvec) {
        cout << format("{}: {}\n", count, w);
        if(--limit == 0) break;
    }
}
```

### How it works...

cin은 공백 기준으로 끊어 읽기 때문에, 진짜 '단어'로 나누려면 regex가 필요하다. 기본 ECMA 문법에서 `(\w+)`는 `([A-Za-z0-9_]+)`의 단축형이다.

단어를 꺼낼 때마다 `try_emplace()`로 조건부 추가하고, 다 채우면 vector로 `move()` 한 뒤 빈도(1순위)·사전순(2순위)으로 정렬한다.

## 벡터의 벡터로 긴 문장 찾기

텍스트에서 문장 길이를 재는 도구다. 정렬을 위해 벡터의 벡터를 쓴다.

### How to do it

`.`, `!`, `?` 포함 여부로 문장 끝을 판단한다.

```cpp
// 문장의 끝에 도달했는지 판단
bool is_eos(const string_view& str) {
    constexpr const char* end_punct{ ".!?" };
    for (auto c : str) {
        if (strchr(end_punct, c) != nullptr) return true;
    }
    return false;
}
```

문장 끝이면 새 빈 벡터를 추가해, 벡터의 벡터로 문장 단위를 나눈다.

```cpp
for (string s{}; cin >> s; ) {
    vv_sentences.back().emplace_back(s);
    if (is_eos(s)) {
        vv_sentences.emplace_back(vector<string>{});
    }
}
```

전체 코드.

```cpp
#include <format>
#include <iostream>
#include <string>
#include <string_view>
#include <vector>
#include <algorithm>
#include <cstring>
#include <memory>

using std::format;
using std::cout;
using std::string;
using std::string_view;
using std::vector;
using std::ranges::sort;
using std::cin;
using std::unique_ptr;

bool is_eos(const string_view & str) {
    constexpr const char * end_punct{ ".!?" };
    for(auto c : str) {
        if(strchr(end_punct, c) != nullptr) return true;
    }
    return false;
}

int main() {
    vector<vector<string>> vv_sentences{vector<string>{}};

    for(string s{}; cin >> s; ) {
        vv_sentences.back().emplace_back(s);
        if(is_eos(s)) {
            vv_sentences.emplace_back(vector<string>{});
        }
    }

    // delete back if empty
    if(vv_sentences.back().empty()) vv_sentences.pop_back();

    sort(vv_sentences, [](const auto& l, const auto& r) {
            return l.size() > r.size();
        });

    constexpr int WLIMIT{10};
    for(auto& v : vv_sentences) {
        size_t size = v.size();
        size_t limit{WLIMIT};
        cout << format("{}: ", size);
        for(auto& s : v) {
            cout << format("{} ", s);
            if(--limit == 0) {
                if(size > WLIMIT) cout << "...";
                break;
            }
        }
        cout << '\n';
    }
    cout << '\n';
}
```

### How it works...

`strchr()`로 문장 부호를 검사한다. (단어 중간에 부호가 있으면 정확히 못 나눈다.)

단어를 마지막 문장 벡터에 넣다가 문장이 끝나면 새 벡터를 시작하고, 마지막에 남는 빈 벡터는 지운다. 그다음 문장을 단어 수 내림차순으로 정렬하고, `WLIMIT`까지만 출력하며 넘치면 `...`을 붙인다.

## multimap으로 작업 목록 만들기

작업에 우선순위를 매기고 역순으로 정렬해 보자. `priority_queue`는 반복자를 못 쓴다. `multimap`은 정렬을 유지하면서 역방향 반복자로 순서대로 볼 수 있다.

### How to do it

```cpp
#include <format>
#include <iostream>
#include <string>
#include <map>

using std::format;
using std::cout;
using std::string;
using std::multimap;

using todomap = multimap<int, string>;

void rprint(todomap& todo) {
    for(auto it = todo.rbegin(); it != todo.rend(); ++it) {
        cout << format("{}: {}\n", it->first, it->second);
    }
    cout << '\n';
}

int main() {
    todomap todo {
        {1, "wash dishes"},
        {0, "watch teevee"},
        {2, "do homework"},
        {0, "read comics"}
    };
    rprint(todo);
}
```

### How it works...

`rbegin()`/`rend()`로 정렬을 건드리지 않고 역순으로 출력한다. multimap이 키 오름차순으로 유지하니, 역순으로 돌면 우선순위 값이 큰 작업부터 나온다.
